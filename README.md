# Emergence tree

A map of phenomena named in the literature. An edge is physical production,
a bound, or a limit.

Live: <https://yaldi-sketch.github.io/emergence-tree/>. Link to a node with
its id, e.g. <https://yaldi-sketch.github.io/emergence-tree/emergence-tree.html#mattercontent>.

- `share/index.html`: front page
- `share/logo.png`: mark on the front page
- `share/emergence-tree.html`: the map (open in a browser)
